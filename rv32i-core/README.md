# rv32i-core — 教学用 RV32I 执行核

从零实现的 RV32I 模拟器（库 + 命令行前端），不依赖任何现成模拟器或外部 crate。

## 覆盖范围

- RV32I 整数运算、分支、跳转，字节 / 半字 / 字访存（64 KiB RAM，小端，**严格对齐**）。
- 特权指令 `CSRRW`、`CSRRS`、`MRET`；仅机器模式，陷阱走**直接入口**（`pc ← mtvec & !3`）。
- `ECALL` / `EBREAK` 按基础 ISA 产生异常（mcause = 11 / 3）；`FENCE` 视为空操作。
- **不实现**：中断、分页、`mstatus`、其它指令扩展；未识别编码一律按非法指令处理。

## 内存映射

| 地址                         | 用途                                          |
|------------------------------|-----------------------------------------------|
| `0x0000_0000 .. 0x0001_0000` | 64 KiB RAM（可取指、可读写）                   |
| `0x8000_0000`                | 接收队列读端口（只读；写它 → 存储访问故障）     |
| `0x8000_0004`                | 发送写端口（只写；读它 → 加载访问故障）         |
| 其它                         | 未映射 → 访问故障                               |

端口语义：读 `RX_ADDR` 每次弹出一个字节（任意访存宽度），空队列按 `0xFF` 处理；
**`rd = x0` 也照常弹出**。写 `TX_ADDR` 把存储值的低 N 字节（小端）追加到发送日志。

## 陷阱约定

- 故障指令不提交任何寄存器 / RAM / 端口副作用；随后写 `mepc / mcause / mtval` 并跳转 `mtvec & !3`。
- `mtval`：取指未对齐 / 取指故障 → 出错地址；非法指令 → 指令原始位；
  访存未对齐 / 访存故障 → 出错有效地址；`ECALL/EBREAK` → 0。
- JAL / JALR / 分支目标未对齐时，异常算在跳转指令头上（链接寄存器不写入）。
  JALR **先清目标最低位、再做 4 字节对齐检查**，两者不可互相替代；`MRET` 同样检查 `mepc`。
- 同一访存既未对齐又越界时，先报未对齐。

## 步数预算

`run(budget)` 的预算被夹到 `MAX_STEPS = 2000` 以内；预算耗尽即停，
返回 `RunReport { trace, state, budget }`，其中 `state` 为当前机器状态快照。
每步轨迹记录执行前后 PC、指令位、助记符、已提交变化与陷阱。


## 命令行用法

```sh
rv32i-core <程序.bin> [--addr 0xN] [--regs 文件] [--ram 文件] [--rx 文件] [--steps N] [--quiet]
```

- `程序.bin`：原始机器码，装载到 `--addr`（默认 0），PC 同时初始化。
- `--regs` 文件：每行 `x5 = 0x2A` 或 `pc / mtvec / mepc / mcause / mtval = 0xV`。
- `--ram` 文件：每行 `0x1000: 78 56 34 12`。
- `--rx` 文件：原始字节，按序压入接收队列。
- `--steps`：步数预算（默认 / 上限 2000）；`--quiet` 只打印最终状态。

```
tests/handcrafted.rs  手工可复核机器码测试（有符号比较、移位、陷阱返回、
                      跨界写入、端口读取、JALR 对齐、CSR 语义、步数预算等）
```
